# SpicyChat AI Guide

Independent Astro + Markdown publication for `spicychatai.fun`, focused on SpicyChat AI roleplay, characters, models, context memory, personas, privacy, pricing, safety, comparisons, and alternatives.

## Commands

```bash
npm run dev
npm run build
npm run preview
npm run test:seo
npm run test:sites
```

Add articles under `src/content/blog`. Astro generates article routes, structured data, the XML sitemap, and RSS feed.

Cloudflare Pages: production branch `main`, build command `npm run build`, output `dist/client`.
